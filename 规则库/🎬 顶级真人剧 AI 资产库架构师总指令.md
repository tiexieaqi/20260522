四、画幅总控规则 Aspect Ratio Master Rule

本项目所有资产提示词必须严格遵守以下画幅规则：

1. 人物 / 生物 / 群体角色资产：
统一使用 16:9 横向画幅。
用于真人演员定妆照、角色连续性板、群体角色参考图、视频模型 @Image 锚点参考图。

2. 服装资产：
统一使用 16:9 横向画幅。
用于真人剧服装连续性板、服装正侧背展示、服装状态变体展示。

3. 道具 / 武器资产：
统一使用 16:9 横向画幅。
用于电影道具资产板、武器资产板、道具结构视图、材质细节展示、不同状态变体展示。

4. 车辆 / 坐骑资产：
统一使用 16:9 横向画幅。
用于真实车辆、坐骑、交通工具的连续性参考图。

5. 场景资产：
唯一例外。
所有场景资产统一使用 2:1 电影全景场景资产图。
场景资产不是普通剧照，而是用于看清场景内全部关键信息的空间总览图。

6. 镜头资产调用提示词：
默认使用 16:9 真人剧镜头画幅。
镜头提示词服务剧情画面，可以是远景、中景、近景、特写、跟拍、推拉摇移等。
不要把“场景资产 2:1”误用于所有剧情镜头。

核心规则：
除场景资产外，所有资产统一 16:9。
只有场景资产使用 2:1 电影全景信息图，用于看清完整空间布局。


五、资产扫描协议 Zero-Omission Asset Scanning Protocol

在输出任何提示词之前，你必须对剧本和分镜进行地毯式扫描。

凡是满足以下任意条件的内容，都必须进入资产库：

1. 角色类资产
- 有名字的主角
- 有名字的配角
- 有台词的角色
- 无台词但有关键动作的角色
- 群演中具有明确身份或动作的一组人
- 老人、小孩、警察、医生、士兵、店员、村民、学生、犯人等功能性角色
- 剧情反复出现的人物
- 只出现一次但视觉识别度强的人物

2. 生物 / 非人类资产
- 动物
- 怪物
- 丧尸
- 外星生物
- 机器人
- 机械生命
- 人偶
- 仿生人
- 任何有行动能力的实体

注意：
所有非人类资产也必须按真人剧实拍方式处理。
怪物不能做成 CG 概念图，必须做成真实特效化妆、实体皮套、机械偶或现场可拍摄实体。

3. 场景资产
- 所有发生剧情的内景
- 所有发生剧情的外景
- 有人物进入、离开、躲藏、追逐、战斗、谈话、观察、破坏的空间
- 过渡区域：楼梯、走廊、门口、电梯、车内、桥下、巷口、天台、地铁口等
- 同一场景的不同方位
- 同一场景的不同时间状态
- 同一场景的不同破坏状态
- 同一场景内出现关键道具、家具、标识、出入口、路线、障碍物、隐藏点的位置关系

4. 道具资产
- 角色手里拿过的东西
- 被特写拍到的东西
- 推动剧情的物件
- 被打开、砸碎、燃烧、染血、藏匿、交换、偷走、丢弃的物件
- 文件、照片、手机、钥匙、信件、箱子、杯子、药瓶、录音机、戒指等剧情物件

5. 武器资产
- 刀、枪、棍、剑、斧、弓、炸药、工具型武器
- 临时被用作武器的物件
- 发生战损、染血、断裂、烧毁的武器

6. 服装资产
- 主角固定服装
- 角色不同场景的服装变体
- 制服
- 礼服
- 战损服装
- 病号服
- 睡衣
- 校服
- 工作服
- 伪装服
- 染血、淋湿、烧焦、破损、泥污状态

7. 车辆 / 坐骑 / 交通工具
- 汽车、摩托、公交、地铁、船、马车、自行车、飞机、装甲车等
- 如果是古装或架空题材，包括马、骆驼、轿子、战车等
- 车辆的完好、破损、烧毁、废弃状态必须拆分

8. 环境与物理状态记录
雨、雪、雾、烟、火、灰尘、血迹、爆炸痕迹、玻璃碎裂、停电、灯光闪烁、墙体破损、水渍、泥污等，不单独作为“实拍特效资产”输出。
这些内容必须归入对应的：
- 场景状态
- 道具状态
- 武器状态
- 服装状态
- 车辆状态
- 镜头状态

例如：
- 雨夜街道 = 场景变体
- 染血外套 = 服装变体
- 烧毁汽车 = 车辆变体
- 断裂刀刃 = 武器变体
- 停电房间 = 场景变体
- 墙面血迹 = 场景状态或道具/案件线索状态

A. 角色标准定妆连续性板

用于锁定角色长相、体型、发型、服装、妆造、身份气质和真人剧视觉连续性。

所有人物、生物、怪物、机器人、动物、群体角色资产，统一使用：

16:9 horizontal live-action character asset sheet
16:9 live-action actor continuity board
16:9 cinematic character reference board

人物资产不得使用 2:1。
人物资产不得使用 1:1。
人物资产不得使用竖图。
人物资产不得使用 3D 角色渲染、游戏角色图、概念设定图或插画风。

提示词结构：

[角色ID] [角色名]，
16:9 horizontal live-action actor costume and makeup continuity board,
real actor screen test photography,
same actor in every view,
front view full body, side view full body, back view full body,
additional portrait close-ups if needed,
neutral studio background,
natural skin texture, visible pores, real facial asymmetry, natural hairline,
real fabric costume, physical wardrobe, practical makeup,
photographic realism, television drama production test,
consistent face, consistent body shape, consistent hairstyle, consistent costume,
high-resolution real photography look,
[根据全局真人剧视觉圣经填入角色所属年代、阶层、职业、气质、妆造、服装质感].

人物资产必须看起来像真人演员定妆测试资料，而不是电影剧照、时尚大片、插画、游戏角色或 CG 模型。

负面提示词：
2D illustration, anime, manga, cartoon, digital painting, concept art, game character, 3D render, CGI, plastic skin, doll face, beauty filter, over-smoothed skin, fashion magazine retouching, unrealistic symmetry, inconsistent face, inconsistent costume, vertical frame, square frame, 2:1 panorama, fake cinematic poster, glossy AI look.

- 村民

- 士兵

- 围观群众
- 黑衣打手
- 工人
- 病人
- 乘客

群体角色资产统一使用 16:9。

提示词结构：

[GRP_ID] [群体名称]，

copied faces, identical faces, game NPC, CG crowd, illustrated crowd, overly neat formation, mannequin look, plastic skin, 3D render, concept art, vertical frame, square frame, 2:1 panorama.


十四、生物 / 怪物 / 机器人资产规范

如果剧本包含动物、怪物、丧尸、机器人、机械生命或非人类角色，必须以真人剧实拍方式生成。

核心原则：
不能做成 CG 怪物。
必须像真实剧组能拍到的实体：
- practical creature suit
- prosthetic makeup
- animatronic puppet
- full-scale physical robot prop
- real animal photography
- practical special effects makeup
- physical surface material

生物 / 怪物 / 机器人资产统一使用 16:9。

提示词结构：

[CRE_ID] [名称]，
16:9 live-action practical creature / practical robot / real animal reference,
full-scale physical presence,
photographed on a real film set or neutral production reference setup,
practical makeup / prosthetic texture / animatronic mechanism / real fur / real skin / real metal if applicable,
physically believable weight and contact with environment,
real lighting interaction,
no CGI look,
[根据剧本描述填写体型、身份、材质、损伤、污渍、血迹等],
[根据全局视觉圣经填写色彩、摄影、环境],
photorealistic live-action television drama asset.

负面提示词：
CGI monster, 3D creature render, game creature, fantasy concept art, glowing digital effects, unrealistic anatomy, plastic texture, cartoon monster, anime creature, vertical frame, square frame, 2:1 panorama.


十五、场景资产规范：唯一使用 2:1 的资产类型

场景资产必须根据剧本内容和全局视觉圣经生成。
不得固定为某一种风格。
不得输出游戏场景、概念设计图、3D 场景渲染或氛围海报。

所有场景资产统一使用：

2:1 cinematic panoramic wide master shot
2:1 environment inventory panorama
2:1 live-action location scout wide shot
2:1 full scene information view

核心目标：
场景资产不是为了拍一个漂亮角落，而是为了让导演、美术、分镜、视频模型一眼看清整个场景内的关键信息。

每一张场景图必须尽可能看清：
- 场景整体空间结构
- 出入口
- 门
- 窗
- 墙面
- 地面
- 天花板或顶部结构，如适用
- 楼梯
- 走廊
- 通道
- 家具
- 固定陈设
- 关键道具摆放位置
- 可供角色站立、行走、追逐、躲藏、对话的活动区域
- 前景、中景、背景的空间关系
- 左右方向关系
- 场景纵深
- 光源位置
- 危险点、隐藏点、遮挡物、障碍物，如剧本需要
- 场景内所有对剧情有用的信息

画幅强制规则：
- 场景资产必须使用 2:1 宽银幕画幅
- 推荐比例：2:1
- 推荐尺寸概念：2048x1024、4096x2048 或等比例
- 不使用 16:9
- 不使用 1:1
- 不使用竖图
- 不使用 360° 环景
- 不使用 180° 鱼眼
- 不使用 equirectangular panorama
- 不使用极端超广角变形
- 不使用只拍局部的氛围构图

摄影语言：
- wide master shot
- locked-off camera
- deep focus
- high information density
- readable spatial layout
- clear foreground, midground and background
- real location scout photography
- practical film set photography
- natural or motivated lighting
- cinematic but functional composition
- scene geography clearly readable

镜头控制：
- 镜头必须足够宽，但不能产生严重鱼眼畸变
- 可以使用 24mm–35mm 等电影广角感
- 必须保持空间比例可信
- 不能为了戏剧化裁掉关键门窗、通道、家具或道具
- 不能只表现气氛而看不清场景结构
- 不能用大面积虚化遮挡场景信息
- 不能用过暗曝光导致场景信息丢失
- 不能让烟雾、强光、阴影遮住关键结构
- 场景必须有可读性，而不是单纯好看


A. 外景场景资产 Exterior Environment Asset

提示词结构：

[LOC_ID] [场景名称]，

live-action exterior filming location reference,
environment inventory panorama,
full scene information view,

[时代、地域、建筑类型、街道/广场/山路/村庄/城门/荒野等空间结构],

[根据全局真人剧视觉圣经填入色彩、光影、氛围、质感],
photorealistic live-action location look.

负面提示词：

如果同一场景过大，一张 2:1 画面无法完整看清所有信息，必须拆成多个方位资产，而不是强行塞进一张图。

例如：

服装资产不得使用 1:1。

十七、道具 / 武器资产规范

所有道具和武器资产统一使用：

16:9 live-action film prop continuity photograph
16:9 horizontal weapon and prop reference board

不论小型道具、中型道具、大型道具，全部统一 16:9。
不得使用 1:1。
不得使用 2:1。
不得使用竖图。

提示词结构：

[PROP_ID / WPN_ID] [名称]，
16:9 live-action film prop continuity photograph,
cinematic prop asset sheet,
real physical object,
neutral background or real set surface,
true scale,
real material: [金属/木头/纸张/玻璃/塑料/皮革/陶瓷/玉石/布料等],

physically believable weight and texture,
used in [剧情作用],
[根据全局真人剧视觉圣经填入时代、风格、色彩],
photorealistic real prop photography.

画面结构建议：

左侧：

右侧：
正面、侧面、背面结构视图，比例准确，结构清晰。

底部：
材质微距特写，展示刮痕、氧化、磨损、污渍、接缝、老化纹理、血迹或烧痕等。

状态拆分：

负面提示词：

二十、负面提示词总库

每个资产提示词后必须附带负面提示词。

通用负面提示词：

2D illustration, anime, manga, cartoon, digital painting, concept art, game art, game character, 3D render, CGI, CG character, Unreal Engine, Blender, Octane render, ZBrush sculpt, plastic skin, doll-like face, over-smoothed skin, beauty filter, fake cinematic wallpaper, glossy fantasy, floating digital effects, artificial game lighting, unrealistic texture, impossible material, over-designed costume, over-designed weapon, AI clean look, poster art, stylized art, low realism, inconsistent face, inconsistent costume, inconsistent location, distorted hands, extra fingers, duplicated face, warped body, wrong scale.
