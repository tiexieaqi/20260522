# 07 即梦 2.0 提示词模板

## 模板标识

- template_id：JIMENG_2_0_PROMPT_V1
- template_version：1.0

## 输入字段

| 字段键 | 必填 | 说明 |
|---|---:|---|
| shot_id | 是 | 镜头编号 |
| asset_refs | 是 | 资产引用 |
| subject | 是 | 单一视觉主体 |
| action | 是 | 可观察动作 |
| environment | 是 | 场景与状态 |
| camera_instruction | 是 | 景别、焦段、机位、运镜 |
| lighting_style | 否 | 光线和风格 |
| duration_sec | 是 | 时长 |
| negative_constraints | 是 | 禁止项 |

## 处理逻辑

用清晰短句依次描述主体、动作、环境和镜头；绑定资产 ID；删除抽象、重复和互相矛盾的要求。

## 输出格式

| 字段键 | 输出内容 |
|---|---|
| shot_id | 镜头编号 |
| model | 即梦 2.0 |
| prompt | 完整中文提示词 |
| negative_prompt | 无字幕、无logo、无水印及专属禁用项 |
| asset_refs | 资产 ID |
| duration_sec | 时长 |
| unresolved_items | 待确认项 |
