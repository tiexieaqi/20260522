# 10 成片质量检查模板

## 模板标识

- template_id：FINAL_FILM_QC_V1
- template_version：1.0

## 输入字段

| 字段键 | 必填 | 说明 |
|---|---:|---|
| project_id | 是 | 项目标识 |
| final_video | 是 | 完整成片 |
| final_script | 是 | 最终剧本 |
| final_storyboard | 是 | 最终分镜 |
| asset_library | 是 | 最终资产表 |
| delivery_spec | 否 | 分辨率、画幅、时长、格式等 |
| historical_review | 否 | 历史真实性报告 |

## 处理逻辑

1. 核对成片与剧本、分镜和资产库的一致性。
2. 检查故事完整、节奏、情绪、对白、口型、声音和剪辑衔接。
3. 检查人物、场景、道具的全片连续性。
4. 检查画面缺陷、技术规格、字幕、logo、水印和版权风险标记。
5. 历史题材复核时代、语言、服化道和事件真实性风险。

### 质量检查表

| check_id | category | result | severity | timecode | issue | required_action |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

### 交付结论

| 字段键 | 输出内容 |
|---|---|
| final_result | 可交付/修正后交付/不可交付 |
| blocking_issues | 阻断问题 |
| visual_continuity | 视觉连续性结论 |
| narrative_quality | 叙事质量结论 |
| technical_compliance | 技术规格结论 |
| historical_authenticity | 历史真实性结论 |
| final_action_list | 最终修改清单 |
