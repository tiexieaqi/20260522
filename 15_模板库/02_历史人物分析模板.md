# 02 历史人物分析模板

## 模板标识

- template_id：HISTORICAL_CHARACTER_ANALYSIS_V1
- template_version：1.0

## 输入字段

| 字段键 | 字段名称 | 必填 | 说明 |
|---|---|---:|---|
| person_name | 人物姓名 | 是 | 历史人物名称 |
| script_text | 相关剧本内容 | 是 | 涉及人物的段落或场次 |
| period | 时代 | 否 | 年代与政权 |
| locations | 活动地点 | 否 | 地理范围 |
| provided_sources | 用户提供史料 | 否 | 书目、文章或档案 |
| project_portrayal | 项目人物设定 | 否 | 剧中身份和功能 |

## 处理逻辑

1. 区分史实、项目改编和未知信息。
2. 分析人物身份、经历、关系、立场和时代处境。
3. 提取与剧本直接相关的核心事件和时间顺序。
4. 检查年龄、地点、官职、称谓、制度、语言和物件风险。
5. 没有可靠依据的内容标记 `待核实`，不得写成确定史实。

## 输出格式

| 字段键 | 输出内容 |
|---|---|
| person_name | 人物姓名 |
| historical_background | 人物背景 |
| era_environment | 时代环境 |
| core_events | 核心事件列表 |
| relationships | 关键关系 |
| project_portrayal | 项目中的塑造方式 |
| confirmed_facts | 已确认史实 |
| adaptation_elements | 明确的艺术改编 |
| authenticity_risks | 真实性风险及等级 |
| verification_items | 待核实事项 |
| source_references | 依据来源 |
