# 03 资产库生成模板

## 模板标识

- template_id：ASSET_LIBRARY_GENERATION_V1
- template_version：1.0

## 输入字段

| 字段键 | 字段名称 | 必填 | 说明 |
|---|---|---:|---|
| project_id | 项目标识 | 是 | 与项目档案一致 |
| script_text | 剧本正文 | 是 | 含场次和对白 |
| storyboard_text | 分镜内容 | 否 | 已有分镜 |
| character_notes | 人物小传 | 否 | 已确认人物资料 |
| visual_bible | 视觉圣经 | 否 | 项目专属视觉规则 |
| existing_assets | 已有资产表 | 否 | 用于续编和防重复 |

## 处理逻辑

1. 扫描有台词、关键动作或剧情作用的人物，生成 `CH-001` 起的编号。
2. 扫描地点和空间状态，生成 `LOC-001` 起的编号。
3. 扫描剧情道具，生成 `PROP-001` 起的编号。
4. 扫描武器，生成 `WPN-001` 起的编号。
5. 扫描有明确身份或动作的人群，生成 `GRP-001` 起的编号。
6. 同一资产状态变化建立变体并关联基础资产。
7. 保留原文依据；未知细节标记 `待确认`。

## 输出格式

### 资产总表

| asset_id | category | name | source_reference | scenes | story_function | fixed_anchors | variable_states | status | pending_items |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |

### 资产变体表

| variant_id | base_asset_id | state | reason | scenes | key_differences | separate_image_required |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

### 分类输出顺序

1. CH 人物资产
2. LOC 场景资产
3. PROP 道具资产
4. WPN 武器资产
5. GRP 群体资产
