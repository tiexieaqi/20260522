# 09 视频审核模板

## 模板标识

- template_id：VIDEO_REVIEW_V1
- template_version：1.0

## 输入字段

| 字段键 | 必填 | 说明 |
|---|---:|---|
| shot_id | 是 | 镜头编号 |
| generated_video | 是 | 待审核视频 |
| storyboard_record | 是 | 原分镜记录 |
| prompt_record | 是 | 生成提示词 |
| asset_references | 是 | 资产参考 |
| previous_shot | 否 | 上一镜头 |
| next_shot | 否 | 下一镜头 |

## 处理逻辑

1. 核对主体、动作、景别、运镜、时长和台词口型。
2. 检查人物五官、服装、场景、道具和轴线连续性。
3. 检查变形、闪烁、穿模、肢体异常、物体漂移和画面抖动。
4. 检查字幕、logo、水印、乱码和多余界面元素。
5. 按严重程度给出通过、修改后通过或重生成结论。

## 输出格式

| issue_id | category | timestamp | severity | description | expected | correction_action |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

| 字段键 | 输出内容 |
|---|---|
| review_result | 通过/修改后通过/重生成 |
| critical_issues | 严重问题数量 |
| continuity_score | 连续性结果 |
| lip_sync_result | 口型审核结果 |
| prohibited_content_result | 字幕/logo/水印审核结果 |
| retry_instructions | 重生成修改指令 |
