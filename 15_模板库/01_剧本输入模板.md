# 01 剧本输入模板

## 模板标识

- template_id：SCRIPT_INPUT_V1
- template_version：1.0

## 输入字段

| 字段键 | 字段名称 | 必填 | 说明 |
|---|---|---:|---|
| project_name | 项目名称 | 是 | 故事或剧本名称 |
| source_text | 故事原文 | 是 | 梗概、大纲或剧本正文 |
| work_type | 作品类型 | 否 | 电影、短剧、连续剧等 |
| genre | 题材类型 | 否 | 历史、战争、悬疑等 |
| period | 时代背景 | 否 | 年代或具体时间 |
| location | 主要地点 | 否 | 国家、地区或具体场所 |
| target_duration | 目标时长 | 否 | 单集或全片时长 |
| episode_count | 集数 | 否 | 单部填 1 |
| target_platform | 发布平台 | 否 | 目标播放平台 |
| style_reference | 风格参考 | 否 | 只提取规律，不复制内容 |
| user_requirements | 用户要求 | 否 | 特殊限制或目标 |

## 处理逻辑

1. 检查必填字段和文本完整性。
2. 从原文提取类型、时代、地点、主要人物、核心事件、冲突、主题和结局状态。
3. 区分用户明确提供的信息与系统推断。
4. 不确定信息统一标记 `待确认`，不得自行补写。
5. 生成标准化项目输入摘要，供剧本分析和资产提取调用。

## 输出格式

| 字段键 | 输出内容 |
|---|---|
| project_id | 项目唯一标识 |
| project_name | 项目名称 |
| work_type | 标准化作品类型 |
| genre | 标准化题材 |
| period | 时代背景 |
| primary_locations | 主要地点列表 |
| main_characters | 主要人物列表 |
| core_event | 核心事件 |
| central_conflict | 核心冲突 |
| theme | 主题 |
| duration_and_episodes | 时长与集数 |
| confirmed_constraints | 已确认约束 |
| pending_questions | 待确认问题列表 |
| source_reference | 原文段落或位置 |
