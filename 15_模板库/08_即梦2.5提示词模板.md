# 08 即梦 2.5 提示词模板

## 模板标识

- template_id：JIMENG_2_5_PROMPT_V1
- template_version：1.0

## 输入字段

| 字段键 | 必填 | 说明 |
|---|---:|---|
| shot_id | 是 | 镜头编号 |
| asset_refs | 是 | 资产与状态变体 |
| start_state | 是 | 起始画面 |
| action_sequence | 是 | 动作过程 |
| end_state | 是 | 结束画面 |
| camera_instruction | 是 | 主镜头语言 |
| rhythm | 否 | 动作与镜头节奏 |
| duration_sec | 是 | 时长 |
| negative_constraints | 是 | 禁止项 |

## 处理逻辑

检查动作可执行性和状态连续性；控制动作数量；保留一套主镜头逻辑；将物理状态变化关联到正确资产变体。

## 输出格式

| 字段键 | 输出内容 |
|---|---|
| shot_id | 镜头编号 |
| model | 即梦 2.5 |
| prompt | 连续动作提示词 |
| negative_prompt | 无字幕、无logo、无水印及专属禁用项 |
| asset_refs | 资产与变体 ID |
| duration_sec | 时长 |
| continuity_notes | 连续性说明 |
| unresolved_items | 待确认项 |
