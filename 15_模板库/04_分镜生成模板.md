# 04 分镜生成模板

## 模板标识

- template_id：STORYBOARD_GENERATION_V1
- template_version：1.0

## 输入字段

| 字段键 | 字段名称 | 必填 | 说明 |
|---|---|---:|---|
| project_id | 项目标识 | 是 | 当前项目 |
| scene_id | 场次编号 | 是 | 剧本场次 |
| scene_text | 场次正文 | 是 | 动作与对白 |
| asset_library | 资产表 | 是 | CH/LOC/PROP/WPN/GRP |
| target_duration | 场次目标时长 | 否 | 秒 |
| aspect_ratio | 画幅 | 否 | 默认继承项目规则 |
| model_target | 目标视频模型 | 否 | Seedance 或即梦版本 |

## 处理逻辑

1. 按动作、情绪、信息和对白切分镜头。
2. 镜头编号使用 `场次编号-SHOT序号`。
3. 为每镜选择时长、景别、焦段、机位和运镜。
4. 描述可观察动作，并保留对白原文与口型同步要求。
5. 仅引用已有资产 ID；缺失资产进入待补资产清单。
6. 检查相邻镜头轴线、视线、动作和服化道连续性。

## 输出格式

| shot_id | duration_sec | shot_size | focal_length | camera_position | camera_movement | action | dialogue | lip_sync | asset_refs | continuity | prohibitions |
|---|---:|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  | 无字幕、无logo、无水印 |
