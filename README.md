# AI影视助手

这是一个用于辅助剧本创作、检查和修改的基础项目。

## 文件夹说明

- **输入剧本**：放入需要分析或修改的剧本文件。
- **输出结果**：保存 AI 分析、诊断或修改后的结果。
- **规则库**：保存给 AI 使用的规则和工作方法。新规则可以参考 `规则模板.md` 创建。
- **程序**：预留给后续程序文件，目前不需要操作。

## 当前状态

项目已完成基础初始化。现有规则文件保留不变，并新增了一个通用规则模板。

## 下一步怎么操作

1. 把一个需要处理的剧本文件复制到“输入剧本”文件夹。
2. 打开“规则库”，选择最符合需求的规则文件；刚开始可以先使用已有的剧本写作或剧本医生规则。
3. 将剧本内容和规则一起交给 AI，并说明你想完成的任务，例如“检查人物动机”或“优化这场戏的台词”。
4. 把 AI 返回的结果保存到“输出结果”文件夹，并用清楚的文件名标记，例如 `第一集_人物动机检查.md`。
5. 如果以后需要增加规则，请复制 `规则模板.md`，填写内容后再使用。

## 使用建议

刚开始只处理一个小片段或一场戏，确认结果符合预期后，再处理完整剧本。
