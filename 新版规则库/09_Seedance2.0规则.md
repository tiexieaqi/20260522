# 09 Seedance 2.0 规则

## 一、适用范围

本文件为模型适配层；必须服从系统总控、通用制作规则和项目资产 ID。

## 二、提示词结构

主体/资产 ID、动作、场景/LOC ID、镜头语言、光线、情绪、时长、连续性约束、负面限制。

## 三、失败规避

- 一条提示只保留清晰且可执行的主体动作和镜头运动。
- 不混用互相矛盾的景别、焦段、运镜、时长和动作。
- 明确要求无字幕、无 logo、无水印；使用固定资产锚点。

## 四、来源与待验证项

- 通用来源：《资产库架构师总指令》的 @Image 锚点、镜头调用和负面提示词章节。
- 历史 Skill 未提供 Seedance 2.0 专属语法或参数；具体平台行为需后续实测补充。

## 规则目标

把通用镜头和资产约束转换为 Seedance 2.0 可执行提示词。

## 适用范围

Seedance 2.0 的图生视频/文生视频提示词和失败复盘。

## 核心规则

按主体、动作、场景、镜头、光线、情绪、时长和负面限制组织；使用资产 ID 固定连续性。

## 禁止事项

禁止在一条提示中堆叠冲突动作、冲突运镜、多个时空或字幕/logo/水印。

## 执行检查清单

- [ ] 主体和资产 ID 明确
- [ ] 动作与镜头只有一套主路径
- [ ] 时长和连续性约束已写
- [ ] 已写无字幕/logo/水印限制
