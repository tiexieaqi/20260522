# 11 即梦 2.0 规则

## 一、适用范围

本文件为模型适配层；遵守通用分镜、资产连续性和生成禁用项。

## 二、提示词结构

主体/资产 ID、动作、场景、景别与运镜、光线、风格、时长、负面限制。

## 三、失败规避

- 使用短句表达单一主体动作，避免抽象或互相冲突的要求。
- 以 CH/LOC/PROP 资产和变体表固定连续性。
- 明确无字幕、logo、水印和界面元素。

## 四、来源与待验证项

- 通用来源：《资产库架构师总指令》的资产提示词字段和审校清单。
- 历史 Skill 未提供即梦 2.0 专属规则，需后续实测。

## 规则目标

将分镜和资产信息整理为即梦 2.0 清晰、短句化的生成提示词。

## 适用范围

即梦 2.0 的图像/视频生成提示词。

## 核心规则

单一主体动作，明确场景、景别、运镜、光线、时长和资产锚点。

## 禁止事项

禁止抽象空话、互相矛盾的风格/运动要求及字幕、logo、水印。

## 执行检查清单

- [ ] 主体动作可观察
- [ ] 景别与运镜一致
- [ ] CH/LOC/PROP 已绑定
- [ ] 已加入负面限制
