# 05 人物资产规则

## 一、人物资产

每名有台词、关键动作或影响剧情的角色建立 CH 资产；记录长相、体型、年龄感、发型、妆造、服装、身份气质和固定锚点。

## 二、连续性

- 五官、体型、发型、服装、妆造和关键道具保持一致。
- 时间、受伤、换装或剧情状态变化拆为独立变体，记录场次和变化原因。
- 不把电影状态剧照混作标准定妆连续性板。

## 三、来源

- 《资产库架构师总指令》：人物角色资产、群体角色资产、资产变体章节。
- 《剧本创作 Skill v2.0》：项目档案与不捏造规则。
- 《Skill 4》：角色辨识度、年代语言锚定。

## 规则目标

锁定角色可识别外观和跨场次连续性。

## 适用范围

主要角色、配角、群体角色及其服装、妆造和状态变体。

## 核心规则

CH 资产固定五官、体型、发型、服装、妆造、身份气质和关键道具；变化按场次拆变体。

## 禁止事项

禁止随意更换五官、年龄感、服装、时代感或把状态剧照当定妆基准。

## 执行检查清单

- [ ] CH 编号唯一
- [ ] 五官和服装锚点完整
- [ ] 变化有原因、场次和变体 ID
- [ ] 与项目档案一致
