# 07 道具资产规则

## 一、PROP 资产

提取推动剧情、被角色操作或具有识别作用的道具和武器，记录用途、材质、尺寸、重量感、出现场次和剧情作用。

## 二、连续性

- 使用、损坏、沾污、缺失、装卸或数量变化拆为独立状态变体。
- 道具资产使用 16:9；剧情镜头通过 PROP ID 调用。

## 三、来源

- 《资产库架构师总指令》：道具/武器资产、变体和调用表章节。

## 规则目标

保证 PROP 道具在功能、外观、材质和状态上的跨镜头一致。

## 适用范围

剧情关键道具、武器、服装附属物和可被角色操作的物件。

## 核心规则

记录用途、材质、尺寸、重量感、场次和状态；使用/损坏/沾污/数量变化拆变体。

## 禁止事项

禁止遗漏关键道具、混用状态、改变功能或将虚构细节当剧本事实。

## 执行检查清单

- [ ] PROP 编号唯一
- [ ] 功能与外观已登记
- [ ] 状态变体有场次依据
- [ ] 镜头调用正确资产
